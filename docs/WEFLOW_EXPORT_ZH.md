# 怎么导出聊天记录

Alchemy Hive 推荐用 **WeFlow 导出 JSON**（信息最全），但**输入不限于 WeFlow**——任何平台的聊天导出，只要解析得出消息，都能蒸馏。

## 不是 WeFlow 也能用

自动识别平台（`alchemy-hive import` 直接吃，或 GUI 选「来源平台」）：

- **Telegram**：桌面端「导出聊天记录」→ 勾 Machine-readable JSON，`messages[{type, date, from, text}]` 结构直接解析
- **WhatsApp**：会话「导出聊天」→ txt，`[MM/DD/YY, h:mm AM/PM] 发送者: 内容` 格式直接解析（图片/文件行自动跳过）
- **Instagram / Facebook**：Meta 数据下载里的 `message_*.json`（`sender_name / content / timestamp_ms` 结构）直接解析，自动按时间排序
- **微信 txt**：`时间戳 '发送者'` 两行格式
- **通用兜底**：识别不出时按 `content/sender/time` 这类常见字段名探测，其他平台也能捞

这些平台导出**不带方向标记**（不标哪边是你），蒸馏前用 `--self` 告诉工具你的昵称，你的消息会被归为「我」：

```bash
alchemy-hive import telegram.json --name 对方 --self 你的昵称
```

## WeFlow（推荐）

1. 从 [WeFlow](https://github.com/hicccc77/WeFlow) 下载安装，微信扫码登录——完全本地运行，不上传数据
2. 左侧选**私聊会话**，进会话右上角找「导出」
3. 格式选 **JSON**，**务必勾选「包含双方消息」**——只导自己发的会丢一半素材，蒸馏出来严重走样
4. 得到 `.json` 后直接 `alchemy-hive import` 就能吃

只支持单聊。群聊的多人与消息结构更复杂，暂不支持。

## 微信 txt（替代方案）

把微信聊天复制出来整理成 txt，**每两行一组**：

```
2023-07-24 09:29:09 '小明'
内容文字
2023-07-24 09:31:53 '我'
我看看
```

- 第一行：`时间戳 + 空格 + 发送者`（引号可有可无）
- 第二行：消息内容
- 时间格式：`YYYY-MM-DD HH:MM:SS`，小时可以是 `9` 或 `09`
- 编码 UTF-8 / GBK 均可，` `（U+2005）这类特殊空格也能识别

两种格式解析时都会**自动跳过**图片 / 表情 / 链接占位（如 `[图片]`、`[色]`）。

## 常见问题

**Q：蒸馏出来不像 TA？**

先查原料：没勾「包含双方消息」、聊天太少（几百条以下）、没填性格画像。加 `--profile "INTJ 爱吐槽"` 会大幅提升；还不行就用 `--fix` 交互校正。

**Q：数据安全吗？**

WeFlow 本地运行；样本会发往你配置的模型服务。产物 `.agent.json` 含真实聊天内容，**分享或发布前请自行脱敏**（替换姓名 / 号码）。
