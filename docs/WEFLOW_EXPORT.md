# 导出微信聊天记录

本工具需要先把微信聊天记录导出成文件。**推荐用 WeFlow**（导出 JSON，信息最全），也可以用手动整理的微信 txt。

---

## 一、WeFlow 方式（推荐，导出 JSON）

### 1. 安装 WeFlow

从 [WeFlow GitHub](https://github.com/hicccc77/WeFlow) 下载对应系统（Windows / macOS）的安装包并安装。

> WeFlow 是开源项目，**完全本地运行**，不会上传你的聊天数据。

### 2. 扫码登录

打开 WeFlow → 用微信**扫码登录**（需要手机上的微信确认）。

### 3. 选择会话

- 左侧会话列表选择你要蒸馏的**私聊会话**
- 建议选**记录较多**的会话（几百条以上），蒸馏质量才有保证
- 群聊暂不支持，请选单聊

### 4. 导出设置（关键）

进入会话后找「导出」（一般在右上角菜单或设置里）：

- **格式选 JSON**
- **务必勾选「包含双方消息」**——只导自己发的会丢一半素材，蒸馏出来会严重走样

### 5. 得到文件

导出得到 `.json` 文件，即可作为 `alchemy-hive import` 的输入：

```bash
alchemy-hive import 聊天记录.json --name 小明
```

## 二、微信 txt 方式（替代方案）

不用 WeFlow 也能用：把微信聊天复制出来，整理成 txt 保存。格式是**每两行一组**：

```
2023-07-24 09:29:09 '小明'
内容文字
2023-07-24 09:31:53 '我'
我看看
```

规则：
- 第一行：`时间戳 + 空格 + 发送者`（发送者可带引号，也可不带）
- 第二行：消息内容
- 时间格式：`YYYY-MM-DD HH:MM:SS`（小时可以是 `9` 或 `09`）
- 支持 UTF-8 / GBK 编码；` `（U+2005）等特殊空格也能识别

---

## 三、本工具支持的输入格式

| 格式 | 说明 |
|---|---|
| **WeFlow 导出 JSON** | 顶层数组，或 `{messages:[...]}` / `{data:[...]}`；字段兼容 `msgContent/content/text`、`isSend/senderUsername` 等常见命名 |
| **微信导出 TXT** | `时间戳 '发送者'` + 内容 的多行格式，UTF-8/GBK 均可 |

解析时**自动跳过**图片 / 表情 / 链接等占位（如 `[图片]`、`[色]`）。

## 四、常见问题

**Q1：找不到导出按钮？**
不同 WeFlow 版本入口不同，一般在会话页右上角「…」或菜单里找「导出」/「Export」。

**Q2：导出报错或失败？**
- 确认扫码登录有效
- 先试一个小会话（超大会话可能超时）
- WeFlow 版本过旧 → 更新到最新

**Q3：为什么蒸馏出来不像 TA？**
- 没勾「包含双方消息」→ 缺对方视角素材
- 聊天太少（<几百条）→ 分析不出内容，建议用积累更久的会话
- 忘记填性格画像 → 加 `--profile "性格标签"`（如 `"INTJ 爱吐槽 重感情"`）会大幅提升
- 蒸馏完觉得不像 → 用 `--fix` 交互校正

**Q4：导出的数据安全吗？**
WeFlow 本地运行；本工具会把样本发往你配置的模型服务。产物 `.agent.json` 含真实聊天内容，**分享或发布前请自行脱敏**（替换姓名/号码）。

**Q5：能导群聊吗？**
目前建议单聊；群聊的多人结构与消息类型更复杂，后续版本再支持。

## 下一步

```bash
alchemy-hive import 聊天记录.json --name 小明   # 解析
alchemy-hive distill --name 小明                # 蒸馏（需先配置模型 key）
alchemy-hive export --name 小明                 # 导出 .agent.json
alchemy-hive gui                                # 或直接用图形界面
```
